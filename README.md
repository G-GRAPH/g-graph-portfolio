# G GRAPH — Thumbnail Heaven

A minimalist portfolio site for G GRAPH, a graphic design studio for content creators.

## Included
- Responsive homepage with generated placeholder artwork
- Selected work gallery
- About section
- Dedicated contact page with email and phone links
- Soft grey, white, and black visual system

Replace the SVG files in `images/` with your own artwork whenever you're ready. Open `index.html` locally or enable GitHub Pages to publish it.
